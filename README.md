# CyCoAnalysis website

This website visualizes some of the results from our [dataset](https://github.com/CyCoAnalysis/dataset), which is included as a git submodule.
Clone this repository with `git clone --recursive <repo-url>`, or if you already cloned it, run `git submodule update --init`.
You can run the site locally with `bundle exec jekyll serve --livereload --port 4000`.
Contributions to cover more data or improve the visualization are welcome!
